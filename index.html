This presentation demo lets you preview an appointment enquiry. It does not create a real appointment or contact hospital staff.

Are all listed specialities available at the hospital?

The departments are sample content. The final website should list only services verified by the hospital.

Will this website work on mobile phones?

Yes, the layout adapts to desktop, tablet and mobile screens.

Can the website be customised for our hospital?

Yes. Branding, doctors, departments, verified contact details, gallery, maps and a connected booking system can be added for the final version.
